# VibeCode Inspector
![VibeCode Logo](VibeCode_Inspector.png)
Select elements on the page and seamlessly send them to your IDE with captured context.


> [!IMPORTANT]
> **Working Prototype**
> VibeCode Inspector is in active development (Working Vibecoded Prototype). It is not yet available on the Chrome Web Store or VS Code Marketplace. **Manual load required** from the `/chrome-extension` and `/vibecode-bridge-extension` folders.

## 🌍 Supported Ecosystem
- **Browsers**: Chrome, Microsoft Edge, Brave, and other Chromium-based browsers.
- **IDEs**: VS Code, Antigravity, Cursor, and Windsurf.

## 🚀 Key Features
- **🎯 Smart Selectors**: Advanced support for CSS, XPath, and specific selectors.
- **✨ UI Capture**: High-fidelity HTML & CSS extraction.
- **📸 Advanced Capture**: Deep-context capture for complex component hierarchies.
- **🏗️ Multi-Select**: Group multiple elements into a single context payload.
- **📋 Smart Templates**: Customize your prompts with dynamic data modules.
- **🕒 Capture History**: Quickly re-send or review your previous capture history.
- **💾 Custom Presets**: Save and load your favorite prompt templates and configurations.
- **🔔 UX-Friendly Toast**: Draggable, Resizable & Collapsible.
- **📜 More Coming**: More features & improvements are coming.
